# IndiQube location page prototype

## Purpose
Create a location-specific destination for Google Ads and local search without redesigning the existing Boteco website.

## URL
`https://boteco.co.in/indiqube/`

## Design approach
- Reuse the existing homepage video, navigation, menu modals, events, Instagram feed, reservation flow and visual system.
- Change only the location-sensitive parts of the page.
- Keep the page brand-first; do not keyword-stuff "restaurants near me".

## IndiQube-specific changes
- Page title, meta description, Open Graph metadata and canonical URL.
- Restaurant structured data for the IndiQube address.
- Hero: "Brazilian Restaurant on MG Road, Bengaluru".
- Secondary Google Maps directions CTA.
- Compact location/hours/contact band under the hero.
- Fixed IndiQube contact section rather than the generic outlet selector.
- Added the location URL to sitemap.xml.

## Google Ads intent mapping
Recommended final URL for these IndiQube ad groups:
- Near Me Restaurants
- MG Road & Ashok Nagar
- Brazilian & Steak
- Boteco Brand

All should point to `https://boteco.co.in/indiqube/` after this page is reviewed and merged.
